# 🌍 Rumo — Plataforma Web de Turismo

O **Rumo** é um projeto de desenvolvimento web que simula uma plataforma de turismo, permitindo que os usuários explorem destinos, consultem pacotes de viagens, salvem seus destinos favoritos e realizem reservas demonstrativas.

O projeto foi desenvolvido com **HTML5, CSS3 e JavaScript**, com foco na criação de uma interface moderna, responsiva e interativa, aplicando conhecimentos de desenvolvimento Front-end.

## 🚀 Funcionalidades

- **Login e cadastro:** criação de contas e acesso demonstrativo à plataforma.
- **Página inicial:** apresentação de destinos turísticos e pacotes de viagem.
- **Destinos turísticos:** opções como Paris, Maceió, Santorini, Bariloche e Nova York.
- **Favoritos:** possibilidade de adicionar e remover destinos da lista de favoritos.
- **Minha Conta:** área para visualizar e atualizar informações do usuário.
- **Detalhes dos pacotes:** informações sobre hospedagem, transporte, duração, avaliação e preço.
- **Checkout interativo:** formulário com dados do viajante, data da viagem e forma de pagamento.
- **Cálculo automático:** atualização do valor total conforme a quantidade de viajantes.
- **Confirmação de reserva:** geração de um identificador e apresentação dos dados da reserva simulada.
- **Layout responsivo:** interface adaptável a diferentes tamanhos de tela.

## 💻 Como executar o projeto

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server ou um servidor local.
4. Caso não exista uma sessão demonstrativa ativa, você será direcionado para a página de login.
5. Crie uma conta de teste e explore as funcionalidades do Rumo.

O projeto não necessita de instalação de dependências para executar suas funcionalidades principais.

## 🔐 Observações importantes

O Rumo é um projeto educacional e demonstrativo.

O sistema de login utiliza armazenamento no navegador e não possui autenticação segura em servidor. Portanto, devem ser utilizadas apenas credenciais fictícias de teste.

As reservas e as opções de pagamento são simulações. Nenhuma transação financeira ou reserva real é realizada.

## 🎯 Objetivo do projeto

Aplicar conhecimentos de desenvolvimento web na construção de uma plataforma interativa, explorando:

- Estruturação semântica com HTML5.
- Estilização e responsividade com CSS3.
- Manipulação do DOM e eventos com JavaScript.
- Validação de formulários.
- Armazenamento de dados no navegador.
- Navegação e integração entre diferentes páginas.
- Organização e versionamento de código.
